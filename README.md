## 🛠️ Tecnologías utilizadas
- Angular 21 (Standalone, Signals, Control Flow moderno)
- TypeScript
- Bootstrap 5 (CDN)
- Bootstrap Icons (CDN)
- Supabase (Auth + Base de datos)
- Vercel (Deploy)

## 📋 Sprints

### Sprint 1
- Proyecto Angular 21 creado y deployado
- Componentes: Login, Registro, Home, Quién Soy
- Navegación entre componentes sin restricciones
- Componente Quién Soy consume la API de GitHub
- Favicon personalizado
- Paleta de colores de marca propia
- Animaciones CSS de entrada

### Sprint 2
- Autenticación con Supabase (login y registro reales)
- Guards de ruta para proteger páginas privadas
- Home condicional según estado de autenticación
- 3 botones de inicio de sesión rápido

### Sprint 3
- Ahorcado funcional con guardado en DB
- Mayor o Menor funcional con guardado en DB
- Chat en tiempo real con polling cada 3 segundos

### Sprint 4
- Juego Preguntados (API externa)
- Juego propio (QUIZ de marcas de Autos)
- Página de resultados con 4 tablas ordenadas por desempeño
